# Tahoe for Obsidian

The site for Tahoe, a Mac-like theme and six plugins for Obsidian: **https://krishnanefx.github.io/tahoe/**

It lists the packages, with download numbers fetched live from Obsidian's download stats and GitHub, and has short write-ups of how the hardest parts are built.

The packages themselves are in their own repositories:
[theme](https://github.com/krishnanefx/obsidian-tahoe-theme) ·
[Run](https://github.com/krishnanefx/obsidian-tahoe-run) ·
[Math](https://github.com/krishnanefx/obsidian-tahoe-math) ·
[Code](https://github.com/krishnanefx/obsidian-tahoe-code) ·
[Organize](https://github.com/krishnanefx/obsidian-tahoe-organize) ·
[Intelligence](https://github.com/krishnanefx/obsidian-tahoe-intelligence) ·
[Glass](https://github.com/krishnanefx/obsidian-tahoe-glass)

This repository is the built site: plain HTML and CSS, and one small script for the live numbers. Images are from the packages' own repositories.
